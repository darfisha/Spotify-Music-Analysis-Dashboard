This project combined my love for music and data analytics, and here’s how I built it:
1. Data Extraction:
Pulled real-time data using the Spotify API to explore detailed track features and artist metadata.
2. Data Transformation:
Cleaned and shaped the dataset using Power Query to make it analysis-ready.
3. Data Modeling:
Used DAX to perform calculations, create custom metrics, and uncover insights from the data.
4. Visualization:
Designed an interactive, visually rich Power BI dashboard that tells the story of music through data — from tempo trends to genre popularity, artist influence, and more!
